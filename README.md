# Aisha's Little Learning World

A playful, English-language learning dashboard for Aisha, with school planning, healthy eating, coding resources, maths games and achievements.

## Built with
- React
- Vite
- CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Project notes
- The school timetable is a placeholder until the family adds the real schedule.
- Maths questions and healthy-eating content are starter activities, intended to be expanded.
- Progress is stored in the browser's local storage on the device being used.
- No account, analytics, or personal data collection is included in this starter version.
- External learning resources open in a new browser tab.
